# WorkFlow AI - Workplace Productivity Assistant

An integrated workplace assistant built to automate day-to-day administrative burdens including email drafting, meeting action extraction, and prioritized task scheduling.

## 🛠️ Features
- **Smart Email Generator:** Tailors professional communications across distinct workplace tones.
- **Meeting Notes Summarizer:** Extracts structured action items, owners, and decisions from raw transcript text.
- **AI Task Prioritizer:** Sorts unscheduled workplace tasks into focused time blocks.
- **Responsible AI Guardrails:** Embedded system notices and human-in-the-loop review interfaces.
